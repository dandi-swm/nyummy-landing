# nyummy-landing

냐미(Nyummy) 랜딩페이지와 정책 문서. GitHub Pages로 `https://www.nyummy.co.kr`에 서빙한다.

| 경로 | 내용 |
|---|---|
| `/` | 브라우저 언어가 일본어면 `/jp/`, 아니면 `/ko/`로 보낸다 |
| `/ko/`, `/jp/` | 랜딩페이지 |
| `/ko/policy/` | 이용약관, 개인정보처리방침, 계정 삭제 안내 (한국어) |

정책 문서는 이 저장소가 기준이다. 옛 주소 `dandi-swm.github.io/nyummy-policy/`는 출시된 앱(2.2.2 이하)과 Play Console이 쓰고 있어서, 그 버전이 사라질 때까지 `nyummy-policy` 저장소를 지우거나 넘김 페이지로 바꾸지 않는다(앱이 그 주소 밖으로 넘어가면 외부 브라우저로 연다). 정책을 고치면 두 저장소에 같이 반영한다.
