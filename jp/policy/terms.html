Nyummy(ニャミ) 利用規約

施行日: 2026年12月20日（2026年11月20日公開） · 運営: チーム・ダンディ(Team Dandi)

本規約は韓国語版を基準として作成されており、日本語版と韓国語版の解釈に相違がある場合は韓国語版に従います。

第1条（目的）

本規約は、チーム・ダンディ(Team Dandi)（以下「当チーム」といいます）が提供するモバイルアプリケーション「Nyummy(ニャミ)」および関連サービス（以下「本サービス」といいます）の利用条件および手続、当チームと会員の権利・義務および責任事項を定めることを目的とします。

第2条（用語の定義）

  1. 「会員」とは、本規約に同意しアカウントを作成して本サービスを利用する方をいいます。
  2. 「アカウント」とは、会員の識別および本サービスの利用のために、会員がメールアドレスとパスワードにより作成し、またはKakao・Googleアカウントと連携した利用単位をいいます。
  3. 「食事記録」とは、会員がアップロードした食事写真およびこれをもとに作成された料理名、栄養情報等の記録一式をいいます。
  4. 「ニャミ」とは、本サービス内で会員の記録に応じて状態が変化する猫のキャラクターをいいます。
  5. 「アプリ内報酬」とは、コイン、ショップで購入または保有する家具や部屋の背景等のアイテム、称号など、本サービス内でのみ使用される無償のゲーム要素をいいます。

第3条（規約の掲示および改定）

  1. 当チームは、会員が容易に確認できるよう、本規約をアプリのログイン画面および設定画面、ならびに本ページに掲示します。ポリシー文書の基本URLはhttps://www.nyummy.co.kr/ko/policy/へ移行され、従来のURLも当面の間維持されます。
  2. 当チームは、関係法令に違反しない範囲で本規約を改定することができます。
  3. 本規約を改定する場合は、適用日および改定理由を明示し、適用日の7日前からアプリ内のお知らせまたは本ページにて告知します。会員に不利益となる変更については、適用日の30日前から告知します。
  4. 会員は、改定後の規約に同意しない場合、利用を中止して退会することができます。告知において定めた期間内に拒否の意思を示さずに本サービスを継続して利用した場合は、改定後の規約に同意したものとみなします。

第4条（会員登録）

  1. 本サービスの利用を希望する方は、本規約およびプライバシーポリシーに同意のうえ、メールアドレスまたはKakao・Googleアカウントにより登録できます。
  2. 本サービスは満14歳以上の方のみ登録できます。
  3. 当チームは、次の各号に該当する登録申請については承諾せず、または事後に利用契約を解除することがあります。
    • 他人の情報を盗用し、または虚偽の情報を入力した場合
    • 満14歳未満である場合
    • 本規約違反により利用を制限された履歴がある場合
  4. 会員登録時に入力したプロフィール（性別、生年月日、身長、体重）はアプリ内から変更できません。修正が必要な場合は、メールボックスまたはメールにてご依頼ください。

第5条（アカウント管理）

  1. 会員は、自身のアカウントおよびパスワードを自ら管理しなければならず、第三者に譲渡または貸与することはできません。
  2. アカウントが盗用され、または第三者に使用されていることを知った場合は、直ちに当チームへ通知しなければなりません。
  3. ログイン状態はセキュリティのため一定期間経過後に自動的に失効し、再ログインが必要となる場合があります。

第6条（サービスの内容）

当チームは、会員に対して以下のサービスを提供します。

  1. 食事写真の記録およびAI分析による料理名・栄養情報（カロリー、PFC（たんぱく質、脂質、炭水化物））の推定
  2. 食事記録の閲覧、料理名の修正、削除、再分析
  3. 記録に応じて状態が変化する猫のキャラクター「ニャミ」および連続記録日数などのゲーム要素
  4. 食事記録報酬およびイベントプレゼントで獲得するコイン、家具や部屋の背景アイテムを購入できるショップ、保有アイテムを配置するマイルーム機能
  5. 食事時刻通知、分析結果通知などのサービス通知、および同意した会員へ送信するマーケティング通知
  6. メールボックスを通じたお問い合わせの受付および回答
  7. その他、当チームが追加で開発し、または提携を通じて提供するサービス

本サービスは現在無料で提供されており、ショップおよびコインチャージ画面においても実際の金銭決済は発生しません。有料機能を導入する場合は、価格および条件を事前に告知し、会員が別途同意した場合にのみ適用します。

第7条（AI分析結果と健康情報）

  1. AIが分析した料理名および栄養情報は、写真に基づく参考用の推定値であり、実際と異なる場合があります。
  2. 本サービスは医療機器ではなく、疾病の診断・治療・予防を目的としたものではありません。食事管理、ダイエット、疾患管理等については、医師や管理栄養士等の専門家にご相談ください。
  3. 会員は、分析結果に違和感がある場合、料理名を修正し、再分析し、または分析結果を評価して当チームに知らせることができます。

第8条（サービスの利用基準）

  1. 円滑な運営のため、食事記録は1日最大5回まで試行できます。失敗した記録や削除した記録も回数に含まれ、1日は韓国標準時（KST）の午前0時を基準に切り替わります。
  2. 食事記録には、JPEGまたはPNG形式で10MB以下の写真のみアップロードできます。写真に撮影日付情報が含まれている場合は、記録当日に撮影された写真のみ記録できます。
  3. お問い合わせは件名100文字、本文2,000文字以内で作成でき、回答を受ける前まで修正できます。
  4. 当チームは、サービスの運営状況に応じて上記の基準を変更することができ、変更する場合はアプリ内でお知らせします。

第9条（投稿物の権利および利用）

  1. 会員がアップロードした食事写真、お問い合わせ、評価等（以下「投稿物」といいます）の権利は会員に帰属します。
  2. 会員は、当チームが本サービスを提供するために必要な範囲（保存、AI分析、画面表示、エラー分析、分析品質の改善）において投稿物を利用することを許諾します。この許諾は本サービス提供の目的以外に拡張されることはなく、当チームは会員の写真を外部に公開または販売しません。
  3. 会員は、他人の顔、個人情報、著作物を含む写真をアップロードする際、その方の権利を侵害しないよう注意しなければなりません。

第10条（アプリ内報酬、ショップおよびコイン）

  1. コインは食事記録報酬およびイベントプレゼントによってのみ獲得でき、実際の金銭で決済または購入する有償通貨ではありません。
  2. 「コインチャージ」画面は実際の決済が発生しないイベントとして運営されており、会員がタップしたパックに応じてプレゼントコインを獲得できます（テストグループによって提供条件や構成が異なる場合があります）。
  3. 会員は、保有するコインでショップから家具や部屋の背景アイテムを購入でき、カート、購入履歴、コイン履歴、保有アイテム、マイルームの配置情報が本サービスに保存されます。
  4. コインやアイテム等のアプリ内報酬は本サービス内でのみ使用でき、現金価値はなく、現金や財貨への換金・返金、ならびに他の会員への譲渡・貸与・販売はできません。
  5. コインやアイテム等のアプリ内報酬は無償で提供されるものであり、当チームはサービス運営、ゲームバランスおよびイベント実施のため、その種類、獲得条件、価格、使途を変更し、またはイベントを終了することができます。
  6. 退会時、保有しているコイン、アイテム、カート、購入履歴、コイン履歴、マイルーム配置およびニャミの進行状況はすべて消滅し、復元できません。

第11条（通知および広告性情報）

  1. 当チームは、本サービスの利用に必要なサービス通知を送信でき、会員は「設定 > 通知」からこれをオフにできます。
  2. 当チームは、会員がマーケティング通知の受信に同意した場合にのみ広告性情報を送信し、会員は「設定 > 通知」からいつでも同意を撤回できます。
  3. 端末の設定で通知権限をオフにした場合、アプリ内設定にかかわらず通知を受信できなくなります。

第12条（会員の義務）

会員は、以下の行為を行ってはなりません。

  1. 他人の情報の盗用または虚偽情報の登録
  2. わいせつまたは暴力的な写真など、法令または公序良俗に反する投稿物の登録
  3. 他人の著作権、肖像権等の権利侵害
  4. 本サービスへのハッキング、または不正な方法（自動化プログラム、リバースエンジニアリング、サーバーへの過負荷誘導等）による利用行為
  5. アプリ内報酬を不正な方法で取得または取引する行為
  6. 当チームの事前同意なく本サービスを営利目的で利用する行為

第13条（当チームの義務）

  1. 当チームは、関係法令および本規約を遵守し、安定して本サービスを提供するよう努めます。
  2. 当チームは、会員の個人情報をプライバシーポリシーに従って保護します。
  3. 当チームは、会員からのご意見または苦情が正当であると認められる場合、これを処理し、メールボックスまたはメールにて処理結果を通知します。

第14条（サービスの変更および中断）

  1. 当チームは、運営上・技術上の必要に応じて本サービスの内容を変更することができ、重要な変更については事前にアプリ内でお知らせします。
  2. 当チームは、設備の点検・交換、障害、天災地変等のやむを得ない事由がある場合、本サービスを一時的に中断することができます。
  3. 当チームが本サービスを終了しようとする場合は、終了日の30日前からアプリ内のお知らせにて告知します。

第15条（利用制限）

当チームは、会員が第12条に違反した場合、事前案内後に警告、一時停止、利用契約解除等の順序で利用を制限することができます。ただし、法令違反または緊急の被害防止が必要な場合は直ちに制限できます。会員はメールボックスまたはメールにて異議を申し立てることができます。

第16条（退会）

  1. 会員はいつでもアプリの「設定 > 退会」から退会でき、退会は即座に処理されます。アプリを利用できない場合はメールにて申請でき、当チームは遅滞なく処理します。詳しい手順はアカウント削除のご案内をご確認ください。
  2. 退会すると、アカウント情報や食事写真等は削除され復元できません。同じアカウントで再登録しても、以前の記録、ニャミ、コイン、アイテム、マイルーム配置等のアプリ内報酬は引き継がれません。退会後の個人情報の取扱いはプライバシーポリシー第5条に従います。

第17条（責任の制限）

  1. 当チームは、天災地変、通信障害等の不可抗力により本サービスを提供できない場合、責任を負いません。
  2. 当チームは、会員の責めに帰すべき事由により生じた本サービスの利用障害について責任を負いません。
  3. 当チームは、AI分析結果が参考用の推定値であることを告知しており、会員がこれを医学的判断の根拠としたことにより生じた損害については、当チームに故意または重過失がない限り責任を負いません。
  4. 当チームは、無料で提供する本サービスに関連して会員に生じた損害について、当チームに故意または重過失がない限り責任を負いません。

第18条（準拠法および紛争解決）

  1. 本規約および本サービスの利用には、大韓民国法を適用します。
  2. 本サービスの利用に関して紛争が生じた場合、当チームと会員は誠実に協議して解決するものとし、協議が整わない場合は大韓民国「民事訴訟法」に基づく管轄裁判所に訴えを提起することができます。
  3. 本サービスは2026年11月より日本のGoogle Playでも提供されており、日本の利用者に対しても本規約の日本語版をあわせて公開し適用します。
